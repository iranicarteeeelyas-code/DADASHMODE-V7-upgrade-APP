# DADASHMODE V7 · بانک زمان (ارتقای نسخهٔ v5-final)

این بسته روی همان اپ حرفه‌ای فعلی (`DADASHMODE-v5-final`) **اضافه** می‌شود. هیچ فایل v5 حذف یا بازنویسی نمی‌شود؛ فقط `index.html` و `sw.js` چند خط می‌گیرند و قبلش نسخهٔ پشتیبان ساخته می‌شود.

## نصب (۲ دقیقه)
1. محتوای زیپ را **مستقیم داخل پوشهٔ اپ** (کنار `index.html`) باز کنید.
2. ویندوز: روی `start-v7.bat` دوبار کلیک کنید. مک/لینوکس: `./start-v7.sh`
   (یا دستی: `node apply-v7.mjs` و بعد `node tools/serve-v7.mjs`)
3. مرورگر: `http://localhost:3000` و یک بار **Ctrl+Shift+R**.
4. سمت چپ صفحه: **«V7 کنترل»** و **«استودیو کروما»**.
5. در تب «گزارش/تست» → «بارگذاری قسمت V7 در پروژه» تا فیلم‌نامهٔ کتاب V7 (۲۹ سگمنت، ۶۲ خط جمنای) جایگزین شود. نسخهٔ قبلی در تاریخچهٔ نسخه‌ها می‌ماند.

برگرداندن: `node apply-v7.mjs --uninstall` (فایل‌ها می‌مانند) یا یکی از `index.html.bak-v7-*` را جایگزین کنید.

## میان‌برها (فقط در حالت‌های V7؛ میان‌برهای v5 دست‌نخورده)
- همیشه: `C` زیرنویس · `Shift+C` پریست بعدی · `[` `]` سرعت · `Shift+[` `Shift+]` آفست · `-` `=` اندازه · `F2` QR گوشی
- راند ۳: `7`/`9` دهان‌پر اِلیاس/عِماد · `1`/`3` دهان خالی · `4`/`6` جریمه
- راند ۴: `1`/`2` تمام · `0` غلط (آخرین تمام معلق) · `*` چالش
- فروشگاه: `4`–`8` کارت‌ها برای نفری که نوبتش است

## حالت گوشی
گوشی‌ها روی **همان وای‌فای** (یا هات‌اسپات لپ‌تاپ؛ اینترنت لازم نیست). F2 یا تب «گوشی» → QR نقش را اسکن کنید. پین را هر قسمت عوض کنید. رمز واقعی کیف **فقط** از کامپیوتر وارد می‌شود و هرگز روی شبکه نمی‌رود.
